
# ♛ MONARCH OF CONQUEST

### A Fantasy Story Bible & Worldbuilding Archive

MONARCH OF CONQUEST is an interactive Story Bible designed to organise and manage the characters, kingdoms, powers, abilities, lore and story developments of a fantasy universe.

The project takes inspiration from game-style dashboards and RPG interfaces, making worldbuilding feel like managing an evolving game world.

## ✨ Features

- Dark mode and light mode.
- Interactive dashboard.
- Main character profile and character records.
- Editable character attributes.
- RP (Reputation Points) counter.
- KP (Kingdom Points) counter.
- Monarch Gold counter.
- Ability management.
- Treasure collection.
- Achievement records.
- Skills and skill levels.
- Character and villain registries.
- Kingdoms, locations, factions and races.
- Power system and world paths.
- Story chronicle and author's notes.
- Browser-based data saving.
- JSON data export and import.
- Responsive layout for different screen sizes.

## 🚀 How to Use

1. Open the published website in your browser.
2. Navigate through the Story Bible sections.
3. Add or edit records as your story develops.
4. Use the attribute controls to update character statistics.
5. Manage RP, KP and Monarch Gold balances.
6. Export a JSON backup regularly.

## 💾 Data Storage

This version uses browser local storage.

Your records are saved in the browser on the device where you use the application.

Clearing browser data may erase your records. Use the export feature to keep backups.

This version does not currently have cloud synchronisation or user accounts.
